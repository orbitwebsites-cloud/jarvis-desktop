01 // JARVIS 2.1

Built like an app.

01

Cross-app workflows

Read the latest visible message from one app and stage it in another through separate private-read and paste confirmations. JARVIS never auto-sends.

02

Sourced web research

Opens an isolated visible browser, reviews bounded public sources, closes its own session, and creates a Word document with links.

03

Reliable reminders

Schedule relative or clock-time alerts, see live countdowns, snooze in one tap, and avoid marking failed notifications as delivered.

04

Persistent context

Conversation context survives restarts, stays bounded on disk, and can be reset without deleting your memories.

05

Whole-PC control

Launch apps and websites, search files, switch windows, control media, capture screens, and inspect system health.

06

Human authorization

Typing, clipboard reads, process termination, shell commands, and power actions require a one-time confirmation.

07

OmniRoute ready

Connect directly to a local OpenAI-compatible gateway and automatically start a configured OmniRoute service.

08

Reproducible release

The complete Python source, tests, build scripts, dashboard, and release pipeline now live together in one repository.

Deployment sequence

Download once.
Command locally.

  1. 01

    Download JARVIS.exe.

  2. 02

    Close any older JARVIS window.

  3. 03

    Open the new EXE. Existing local settings and memory remain available.

  4. 04

    For AI reasoning, connect OmniRoute or add your own provider keys to %LOCALAPPDATA%\JARVIS\.env.
